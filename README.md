# Infinyty — Website & Pitch Deck

Official repository for the [Infinyty](https://infinyty.netlify.app/) website and interactive pitch deck.

## 🚀 Running Locally

Start the local development server with clean URL support:

```bash
python server.py
```

Then visit:
- **Website:** [http://localhost:3000](http://localhost:3000)
- **Pitch Deck:** [http://localhost:3000/deck.html](http://localhost:3000/deck.html)

Alternatively, you can open `index.html` or `deck.html` directly in any browser.

## 📁 Project Structure

```
├── assets/              # Images, logos, demo videos & favicons
├── index.html           # Home page
├── about.html           # About Us
├── services.html        # Services & Capabilities
├── success-stories.html # Case Studies
├── demos.html           # Interactive Demos
├── careers.html         # Careers & Culture
├── contact.html         # Contact Us
├── deck.html            # 13-Slide Pitch Deck
├── style.css            # Global stylesheet (Light & Dark mode)
├── main.js              # Site interactivity & theme switching
└── server.py            # Local dev server
```

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (Zero build step)
- **Hosting:** [Netlify](https://infinyty.netlify.app/) / [Vercel](https://infinyty-tech.vercel.app/)
